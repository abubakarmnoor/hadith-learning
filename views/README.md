# Hadith Learning — Responsive HTML Website

12 pages: Home, Courses, Course Details, Hadith Library, Hadith Details, Daily Hadith, Quiz, Dashboard, About, Contact, Login, Register.

Open `index.html` in a browser, or run a local server (for example VS Code Live Server). Shared responsive styling and interactions are in `assets/style.css` and `assets/app.js`.

This is a static frontend prototype. Authentication, enrolment, saved progress, contact form delivery, and database features require backend integration. Language selection is a placeholder; full Indonesian/English/Arabic translations and RTL support remain to be implemented. Google Fonts are externally loaded.

Hadith text, Arabic, translations, and references are illustrative samples. Verify against selected authoritative editions and obtain qualified scholarly review before publication.
